# Grass Shader

Procedural grass shader demo built with Three.js.

Interactive WebGL grass field with wind animation, time controls, pause, and compare mode.

## Deployed on Vercel

Live demo: (will be updated after deploy)

## Local development

Just open `index.html` in a browser, or use any static server:

```bash
npx serve .
```

Query params supported:
- `t` — initial time
- `paused=1` — start paused
- `compare=1` — enable compare tint
